# Fonts

Two open-source families, both under the SIL Open Font License 1.1, which
permits redistribution alongside this repository:

- **Poppins** — Indian Type Foundry, Jonny Pinhorn. Display face.
- **Inter** — Rasmus Andersson. Text face.

Only the Latin subset of each weight is stored here (the files the build
embeds). Full families and licence text: <https://fonts.google.com/specimen/Poppins>
and <https://fonts.google.com/specimen/Inter>.
