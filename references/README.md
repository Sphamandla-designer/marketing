# Fisantekraal High School — pre-printed reference documents

Six controlled reference documents that teachers keep in the class file and
read from when completing the two weekly fill-in forms, **SA-01** (register
class) and **SA-02** (subject class). Nothing here is filled in by hand: every
number and code is printed.

The sample set is **Grade 10, FET Phase**, register classes 10A, 10B and 10C,
so that every subject on it is CAPS-correct: Mathematical Literacy exists only
in Grades 10–12, and Civil Technology (Woodworking) and Tourism are FET
electives. Every learner takes seven subjects.

| Code | Document | Sample pages | Used with |
|---|---|---|---|
| RL-01 | Register class list | 10B | SA-01 |
| SL-01 | Split subject class list | 10B-MT, 10B-ML, 10B-TO | SA-02 |
| CL-01 | Combined subject class list | 10ABC-CW | SA-02 |
| SC-01 | Subject code key | Grade 10 (25 subject classes) | SA-02 |
| AT-01 | ATP weekly plan | English FAL Gr 8 T1–T4, History Gr 10 T1–T4 | SA-02, Section C |
| OC-01 | Conduct Observation Code Reference | v0.2 draft, two pages, generated by this build | SA-01 and SA-02, Section B |

Every document carries `VERSION 0.1 · DRAFT FOR CONSULTATION` in its
controlled-reference box and a red status line under the info bar: *Draft for
consultation — placeholder data, not for use in class.*

## Build

```
python3 references/build.py --check --deliver
```

PDFs land in `references/output/`; `--deliver` copies them into
`deliverables/`. `--check` runs the section 10 checks and the build fails if
any check fails:

- every document is exactly one A4 portrait page, inside the 10 mm margins,
  with no type below the stated minimum, nothing shortened to fit a column and
  nothing crossing the footer rule;
- every list is numbered 1..n, alphabetical by surname;
- 10B: RL-01 = MT ∪ ML = CW(10B) ∪ TO, MT ∩ ML = ∅, CW(10B) ∩ TO = ∅;
- a learner who appears on more than one list carries the identical name;
- SC-01's codes equal the set of codes in the data (25 rows) and include every
  code printed on RL-01, SL-01 and CL-01;
- every AT-01 narrative is 230 characters or fewer and never says "your own";
  every ATP code is 4 characters from the allowed set and unique across all
  subjects, grades, terms and weeks;
- no staff surname matches a learner surname, and titles are Mr, Mrs or Ms only;
- OC-01: exactly two pages, 54 codes identical to v0.1, every description
  printed whole on one line, no table text below 9 pt, ▲ and ◆ only on the
  proposed codes;
- the words "Mnr.", "Grade 9", "9A", "9B", "9C", "Woodworking" (outside
  "Civil Technology (Woodworking)"), "SA-OC" and "ISSUED" appear nowhere in
  the output, including the SA-01 and SA-02 blanks in `deliverables/`.

Change the year, term, code rules, version and status in `settings.py`.
Learner, staff and subject data lives in `data.py`.

## AT-01

AT-01 is only built from the official DBE ATP. The build writes one AT-01 page
per term from every file in `references/atp/`:

- `atp/english-fal-grade-8.json` — English First Additional Language, Grade 8,
  Terms 1–4 (10 weeks each).
- `atp/history-grade-10.json` — History, Grade 10, Terms 1–4. Terms 1–3 have
  11 weeks; Term 4 has weeks 1–5 and the final examination (Task 7, 150 marks)
  shown once as "Weeks 6–10" with one narrative and one ATP code.

Narratives are written from the ATP only, in one teacher-facing voice: learner
activities start "Learners …", teacher activities "Teach …" or "Introduce …".
Where the ATP runs a topic over several weeks the content is divided across
those weeks in the ATP's order; where it offers a choice the narrative says
"school chooses one"; each formal task appears in the week it is due; the June
controlled test and end-of-year examination are single sittings across weeks
9–10 (or 10–11 in History).

The ATP code for each week is derived from subject + grade + term + week, so
reprinting a page gives the same codes. Codes use only the handwriting-safe
set: digits 3 4 6 7 9 and letters A C D E F H J K L M N P Q R T W X Y.

## OC-01 v0.2

OC-01 is built from `oc01_data.py` by `oc01.py` as two A4 portrait pages,
printed double-sided on one sheet. Page 1 holds the full OC-01 header, title
bar, info bar and flag legend with the first four categories; page 2 a slim
continuation header with the other five. Both pages carry Leon's footer lines
and "Page X of 2".

- **The 54 codes and their labels are Leon's, exactly as in v0.1.** The build
  fails if the code list differs from the frozen v0.1 list.
- v0.2 adds a one-line description of observable behaviour to every code, in
  the Description column at 9 pt. Allegation codes add "observed or reported".
- **The ▲ and ◆ flags are proposed and await SMT approval.** ▲ (serious): the
  educator receives an incident report link after the form is scanned.
  ◆ (safeguarding): follow the school's protected digital process
  immediately. The build fails if a flag appears on any code other than the
  proposed ones.
- Layout notes: the brief's 6 mm row pitch and 8 mm category bars do not fit
  page 1's four categories under the full header, so the pitch is 5.5 mm and
  the bars 7.5 mm (constants at the top of `oc01.py`); 22 labels are wider
  than the 52 mm Observation column at 9.5 pt bold and take two lines (a
  7.8 mm row) rather than being shortened. Leon's footer lines print one per
  line: at 8 pt on a portrait page the note and the red alert cannot share a
  line, and the controlled line cannot hold the school name as well, so
  "Fisantekraal High School · Page X of 2" sits at the right of the sub-note
  line.

## Design

Matched against the real OC-01 (`Fisantekraal_Conduct_Observation_Code_Reference_Demo`):
the thin rounded frame just inside the page edge, square-cornered title bars and
info panels, the controlled-reference box outlined in dark rather than red,
`Label:` styling in the info bar, and red group bars with white caps for section
headings. OC-01 itself is A4 landscape; these are A4 portrait because the brief
sets that explicitly. SC-01 prints its nine abbreviations in three side-by-side
columns and its 25 subject classes at a 5.5 mm row pitch (9 pt), which is what
lets the whole grade fit one page. RL-01's combined-subject block prints full
width below the whole-class and split blocks so that "Civil Technology
(Woodworking)" is never shortened.
